# Code of Conduct

## Expected behaviour

Be respectful and constructive. Assume good faith. Give and accept
feedback about the work, not the person. Welcome people who are new to
the project or to Swift.

## Unacceptable behaviour

Harassment, insults, personal attacks, sexualized language or imagery,
publishing someone else's private information without consent, and any
other conduct that would be inappropriate in a professional setting.

## Scope

This applies to every space this project maintains: issues, pull
requests, discussions, commits, and any place a contributor represents
the project in public.

## Reporting

Report a violation privately to the maintainer through GitHub's private
vulnerability reporting on this repository, or by direct message to the
maintainer on GitHub. Do not raise it in a public issue or pull request.

## Enforcement

The maintainer decides the consequence for a violation, up to and
including removing content and banning the person involved from the
project's spaces.
